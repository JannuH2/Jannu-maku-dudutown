# Jannu-maku-dudutown 모드 설치 안내

마인크래프트 **1.21.1 / Fabric** 모드 서버용 클라이언트 모드팩입니다.
모드 약 350개와 리소스팩이 자동으로 설치·업데이트됩니다. (서버 주소는 관리자에게 따로 받으세요.)

준비물: **CurseForge 앱**, 인터넷 연결

---

## 처음 설치 (한 번만, 약 10~15분)

**서버 프로필 들어가기**
CurseForge 앱 → Minecraft → **잔누테스트 정식서버**
- 게임 버전: **1.21.1** 에 들어감

**2. 프로필 폴더 열기**
프로필의 **톱니바퀴(⚙) 메뉴 → 폴더 열기**를 누릅니다. 탐색기 창이 열립니다.

**3. update.bat 받기**
[여기를 **우클릭 → 다른 이름으로 링크 저장**](https://raw.githubusercontent.com/JannuH2/Jannu-maku-dudutown/main/update.bat)해서
**2번에서 연 폴더**에 저장하세요. 브라우저가 경고하면 "유지"를 누르면 됩니다.

**4. update.bat 실행**
저장한 `update.bat`을 **더블클릭**합니다.
Windows 파란 경고창이 뜨면 **추가 정보 → 실행**을 누르세요.

**5. 설치 창에서**
- 모드 다운로드가 시작됩니다. 처음에는 수백 MB라서 5~10분 걸립니다.
- 선택 창이 뜨면 **선택 설치 모드**(미니맵, 툴팁 등 편의 기능)를 원하는 것만 체크하세요. 안 골라도 접속에는 문제없습니다.
- "완료되었습니다!"가 나오면 끝입니다.

**6. 게임 켜기**
- (권장) CurseForge 설정 → Minecraft → **메모리 할당 6~8GB**
- CurseForge에서 프로필을 실행하고, 게임 안 **옵션 → 리소스 팩**에서 쓰고 싶은 팩을 켜세요. (자동으로 켜지지는 않습니다)
- 서버에 접속합니다.

## 모드가 업데이트됐다는 공지를 받았을 때

1. 마인크래프트를 **완전히 끕니다.**
2. 프로필 폴더의 **`update.bat`을 더블클릭**합니다.
3. "완료되었습니다!"가 나오면 게임을 켭니다.

옛 버전 모드는 자동으로 지워지니 직접 정리할 필요가 없습니다.

---

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "CurseForge 프로필 폴더가 아닙니다" | `update.bat`이 **프로필 폴더**(위 2번에서 연 곳)에 있는지 확인하세요. |
| "Java를 찾을 수 없습니다" | CurseForge에서 프로필을 **한 번 실행**했다가 끄고 다시 시도하세요. 그래도 안 되면 [adoptium.net](https://adoptium.net)에서 Java 21을 설치하세요. |
| 서버 접속 때 모드/버전이 다르다는 메시지 | 게임을 끄고 `update.bat`을 다시 실행한 뒤 접속하세요. |
| 게임이 켜지다 꺼짐 | 메모리를 6~8GB로 올려보세요. |
| 예전에 모드를 직접 넣은 적이 있음 | 프로필의 `mods` 폴더를 비운 뒤 `update.bat`을 다시 실행하세요. |

해결이 안 되면 오류 화면을 **캡처**해서 관리자에게 보내주세요.
